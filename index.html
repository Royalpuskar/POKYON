Enter the Orbit Rush.

Thread your ship between incoming debris. Survive, earn points, and challenge your reflexes. This is a complete, small browser game — not a 3D commercial release.

POKYON // ORBIT RUSH

Avoid. Adapt. Survive.

Steer using A / D, arrow keys, or the on-screen controls. Dodge hazards and build a higher score.

Keyboard: A/D or ←/→ · P to pause

HOW TO PLAY

Move horizontally to dodge incoming obstacles. You are briefly protected after a collision. A mission ends when the shield reaches zero.

BUILD / EXPERIMENT / IMPROVE

A real project,
with room to grow.

Orbit Rush uses a dependency-free JavaScript simulation and Canvas renderer. The update logic is deterministic and unit-tested. It is a starter for future game mechanics, accessibility and mobile work.
